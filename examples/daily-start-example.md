# 示例：日启简报

以下是一个真实的日启简报示例，展示 `daily-start`（日启）命令的输出。精简版（所有领域最近 3 天内有更新）。

## 输入场景

工作日早上，用户新开一个会话说"日启"。工作区里有 `ACTIVE_BOARD.md`，两个领域（读书、运动）昨天都有日结。

## 输出（精简简报）

```
🎯 当前行动板
🔋 模型：当前 claude-sonnet ｜ 今日建议 例行任务 flash 就够，可降级省钱
Now: 《思考，快与慢》第 4 章阅读（昨天中断点）
Waiting: 无

📍 上次进度
• 读书: 3/38 章读完，锚定效应概念没吃透，12 张卡片已整理
• 运动: 5 公里跑 28 分钟完成，下周目标 27 分

💡 今日建议
先读第 4 章（约 40 分钟），读后套卡片模板做卡，顺便把锚定效应的例子补上。

🔴 待办提醒
- [ ] 重读"锚定效应"章节
- [ ] 用卡片模板补第 4 章
```

## 输出（完整简报，某领域超 7 天未更新时）

```
🎯 当前行动板
Now: 《思考，快与慢》第 4 章
Waiting: 无

📍 上次进度
• 读书: 3/38 章
• 运动: 7 天未更新

💡 今日建议
读书正常推进；运动停了一周，建议今天恢复或从行动板移走。

📊 领域状态
| 领域 | 最后更新 | 活跃度 |
|------|---------|--------|
| 读书 | 昨天 | 🟢 活跃 |
| 运动 | 1月8日 | 🟡 低活跃 |

⚠️ 注意事项
- 运动领域 7 天未更新，确认是否有遗忘任务
```

## 关键规则（命令内部逻辑）

1. **行动板优先**：建议来自 `Now` → `Waiting` → `Next`，旧日志只补充证据；
2. **只读操作**：日启不写任何文件；
3. **30 秒内完成**：只提取标题和中断点，不深读日志全文。
